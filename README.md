## Learning Path

A practical progression is:

1. Start with **Host Split** to practice basic host discovery.
2. Continue with **Midwest Enum Grind** for structured enumeration.
3. Explore **WWW-Data on Midwest** and **Midwest Foothold** for web-user and foothold concepts.
4. Practice credential investigation with **Midwest SSH Credential Hunt**.
5. Study privilege-related analysis with **Sudo Sleuth 4**.
6. Move into Nagios-focused challenges, beginning with **Nagios Profile Hijack**.
7. Investigate **Nagios Secrets in Plain Sight** and **Nagios XI Shadow Enumeration**.
8. Continue with **Nagios XI Crack Pivot** for pivoting-related challenge practice.
9. Finish with **Traverse and Twine** and **PHP Shell Drop** for additional web and shell-focused challenges.

## How to Use the Labs

Use these cybersecurity labs only in environments where you have explicit authorization.

Recommended workflow:

1. Read the individual lab objectives and requirements.
2. Identify the stated target and scope.
3. Perform reconnaissance and enumeration systematically.
4. Record hosts, services, accounts, paths, and relevant observations.
5. Map findings to the security concept represented by the challenge.
6. Perform testing only against the authorized lab environment.
7. Document your methodology, findings, and lessons learned.
